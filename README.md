# Bludit Kategorie-Rechte Plugin

Ein Plugin für [Bludit CMS](https://www.bludit.com) zur Steuerung von Autoren-Rechten
auf Kategorien-Ebene. Autoren dürfen nur ihre eigenen Artikel bearbeiten und nur in
den ihnen zugewiesenen Kategorien veröffentlichen.

## Funktionen

- Blockiert das Bearbeiten und Löschen fremder Artikel
- Mehrfachzuweisung: Autoren können mehreren Kategorien zugewiesen werden
- Setzt Artikel bei falscher Kategorie automatisch auf Entwurf, mit Hinweis an den Autor
- Zuweisungstabelle im Backend, pro Benutzer aufklappbar
- Rückwärtskompatibel zu bestehenden Einzel-Wert-Daten

## Installation

1. Dieses Repository als ZIP herunterladen
2. Den Ordner-Inhalt nach `bl-plugins/kategorie-rechte/` in die Bludit-Installation kopieren
3. Im Bludit-Backend unter **Plugins** das Plugin **"Kategorie-Rechte"** aktivieren
4. Kategorien-Zuweisungen unter **Plugins → Kategorie-Rechte → Einstellungen** vornehmen
